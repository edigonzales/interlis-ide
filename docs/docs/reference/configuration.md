## Wofür ist diese Seite gut?

Diese Seite bleibt für alte Verweise erhalten. Die eigentliche Benutzerreferenz zu den Einstellungen steht jetzt gesammelt unter `Referenz -> Einstellungen`.

## So benutzt du sie

Nutze für den aktuellen Stand die Seite `Einstellungen`. Dort sind die alltagsrelevanten Optionen und die fortgeschrittenen Laufzeit-Einstellungen gemeinsam dokumentiert.

## Darauf solltest du achten

Die alte Aufteilung in mehrere Konfigurationsseiten wurde bewusst reduziert, damit Anwender Einstellungen nicht an mehreren Stellen zusammensuchen müssen.
